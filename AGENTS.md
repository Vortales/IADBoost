# Служебные указания для работы в репозитории

- Перед каждой новой редакцией законопроекта, обращения или другого материала сверяйте её с актуальным содержимым `Правила проекта/`, в том числе с применимыми исключениями и специальными режимами. Наличие законного основания само по себе не гарантирует допустимость действия в конкретной игровой ситуации.
- Правила проекта и коллизии с ними не упоминайте в законопроектах, обращениях, пояснениях или иных предназначенных для пользователя документах. Обнаруженные риски и коллизии объясняйте только отдельно, в личном ответе пользователю; не создавайте отдельный файл с таким разбором.
- Для действующего права используйте 52 JSON в `Законодательная база/`; отсутствующие там акты считать отсутствующими. Архивные законопроекты не являются действующим правом. При недоступности форума не выдавайте локальный срез за проверенную актуальную публикацию.
- Не изменяйте исходные JSON или ранее сданные материалы без отдельного поручения. Не домысливайте даты, номера, подписи, полномочия и факты; проект закона не означает его принятие или вступление в силу.
- В текстах о голосованиях Discord не указывайте числовые ID сообщений: давайте ссылку на канал, при наличии также на конкретную тему, предмет и при необходимости отметку времени. По уточнению пользователя, сотрудники Government имеют доступ к каналу этих голосований; доступ конкретного получателя проверяйте отдельно. Время сообщения не доказывает время окончания голосования; оригиналы архивных выгрузок не изменяйте.
- Новые проекты размещайте в отдельных папках по назначению и сверяйте номера: текущий пакет содержит только ACT. 301-303; ACT. 299-300 и 304-307 перенесены в архив. Исторические проекты с теми же номерами не совпадают с текущими, а ранее снятые ACT. 302-312 не рассматриваются. Проект об обыске в суде ACT. 316 удалён по поручению пользователя. Для DOCX используйте образец ACT. 260, Times New Roman, жирные названия актов, короткое тире `-`, имя `ACT.NNN.<Акт>.docx`; выражайтесь кратко и используйте отсылки вместо повторов. Употребляйте «номер паспорта», а не `ID`. ACT. 235 относится только к IAD.
- В предлагаемых нормах указывайте другой нормативный акт без номеров его статей, в том числе при косвенной отсылке к уже названному акту. Точные ссылки на статьи и части самого изменяемого акта сохраняйте; действующие сравнительные цитаты не искажайте.
- Вызов начальства задержанного по новым предложениям ACT. 302 (ранее ACT. 314) - только инициатором по рации; не переносите это ограничение на связь с адвокатом или вызов прокурора. Сверяйте ранее подготовленные проекты с новыми редакциями источников перед дальнейшим использованием.
- Для будущих заседаний Сената готовьте отдельный BB-код к каждому PNG; протокол не создавайте. Повестку, результаты и журнал составляйте после получения необходимых данных.

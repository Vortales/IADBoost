## Как делается законопроект

1. **Образец — ACT. 260.** Структура: `ACT. NNN` → `IN THE SENATE OF THE STATE OF SAN ANDREAS` → дата → `ЗАКОНОПРОЕКТ` → предмет правки → `SECTION 1. СУТЬ ПРАВКИ.` (1–3 абзаца по существу) → `SECTION. 2. ВНЕСЕНИЕ ПРАВКИ В …` → таблица «настоящая редакция / предложенный вариант», строка на статью. Отсутствующая норма — «В действующей редакции отсутствует.».
2. **Сборка — `tools/make_acts.py`** через `build(bill, outdir)`; тексты берутся из `Законодательной базы/` через `tools/billkit.py`. Левая колонка обязана совпадать с действующей редакцией посимвольно; красный (`F4CCCC`) — то, что меняется, зелёный (`D9EAD3`) — новая редакция, вставки — только зелёным.
3. **Одна коллизия — один законопроект.** Лексика и орфография — один общий акт на все законы.
4. **Сверка с `Новая законка/`** — принимается ли норма и не изменена ли редакция.
5. Файл — `ACT.NNN.<Тема>.docx`, без пробела после номера и без скобок. Правки — в том же файле, новый номер на правку не выдаётся.

## Правила работы с репозиторием

- Действующая редакция акта — только `Законодательная база/` (и её подпапки для не-актов). При двух копиях верна та, у которой `parsed_at` новее.
- Устаревшая редакция не удаляется, а переносится в `Архив/Законодательная база (устаревшие редакции)/` через `git mv`.
- В законопроектах и судебных документах не упоминаются правила серверов и регламенты администрирования: только законодательство штата.
- Иерархия — статья 75 Конституции: Конституция → конституционные законы → законы и кодексы → постановления Сената → акты Губернатора → акты органов и департаментов → локальные акты.
- Следующий свободный номер законопроекта — **296**. Номера 253–258 не переиспользуются; выпуск 272–277 перенумерован в 289–294, номера 272–277 заняты не будут. Проект сенатора, поступивший как «ACT. 294», исправлен и выпущен под номером 295: номер 294 закреплён за лексическим законопроектом.
- Русский язык, законодательный стиль, только короткое тире «-»; личные доводы и оценка «правил проекта» в текст не входят.

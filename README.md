# IADBoost — карта репозитория

Рабочая папка по правовой работе в штате Сан-Андреас: законопроекты, аналитика и судебные документы.

## Что где лежит

| Папка | Что внутри | Статус |
|---|---|---|
| `Законодательная база/` | Актуальные редакции актов штата (Конституция, конституционные законы, кодексы, законы, уставы, формы подачи). По одному файлу на каждую тему форума — самая свежая распарсенная копия. | актуально |
| `Правила проекта/` | Правила серверов Majestic RP: основные, государственные организации, форум и прочее. | справочно |
| `Законопроекты/` | Готовые законопроекты ACT. 230, 235–238, 239–249, 259–269 в DOCX, сгруппированные по выпускам. | сдано |
| `Аналитика/` | Разборы: статус IAD при задержании, исходные заметки (`IAD.txt`). | справочно |
| `Обращения/` | Документы для подачи от частного лица. | к подаче |
| `Архив/` | Сенатский комплект по Указу № 81 — не актуален: Сенат не созывается, документы заменены комплектом в `Обращения/`. | архив |
| `tools/` | Служебные скрипты: сборка DOCX из markdown (`_md2docx.py`), доступ к текстам актов (`fulltext.py`), проверка вёрстки (`check_docx.py`). | служебное |
| `Данные.txt` | Исходные данные по Указу № 81 и заявителю. | вводные |

## Текущая работа

`Обращения/Указ № 81 — жалоба в Верховный суд/`

- `01. Жалоба на несоответствие Указа Губернатора № 81 Конституции штата Сан-Андреас № 91` — готовый документ, MD и DOCX, укомплектован полностью.
- `02. Порядок подачи и проверка` — что сделать, что сверить, сроки, версии актов, разбор названия темы.
- `03. Аудит внешней рецензии` — проверка сторонних замечаний по нормам: что не подтвердилось, что учтено, состояние всех ссылок.
- `04. После подачи — статус и что менять` — влияние статуса заявителя (сенатор, LSCSD IAD) и разбор дефектов уже поданного текста.
- `05. Ходатайство о приобщении документов` — досылка ссылок и уточнение пунктов 2.2 и 4.5, если правка сообщения недоступна.

Название темы на форуме (символ в символ):

> Жалоба на несоответствие Указа Губернатора штата Сан-Андреас № 81 «Об отклонении закона (вето)» от 30.10.2026 Конституции штата Сан-Андреас № 91

Коротко: жалоба подаётся напрямую в Верховный Суд по части 2 статьи 39 Конституционного закона «О судебной системе» — как жалоба на неконституционность нормативного правового акта в отсутствие правоотношений. Прокуратура, Сенат и нижестоящие суды не требуются.

## Правила работы с репозиторием

- Акты берутся только из `Законодательная база/`. При появлении двух копий одного акта верной считается та, у которой в JSON поле `parsed_at` новее — это дата последнего разбора темы на форуме, а не дата файла.
- В законопроектах и судебных документах не упоминаются правила серверов и регламенты администрирования: только законодательство штата.
- Формат DOCX законопроектов — по образцу `Законопроекты/ACT. 230 — Технические исправления в Закон о Национальной Гвардии.docx`.
- Следующий свободный номер законопроекта — **270**.

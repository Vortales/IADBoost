## Правила работы с репозиторием

- Акты берутся только из `Законодательная база/`. При появлении двух копий одного акта верной считается та, у которой в JSON поле `parsed_at` новее — это дата последнего разбора темы на форуме, а не дата файла.
- В законопроектах и судебных документах не упоминаются правила серверов и регламенты администрирования: только законодательство штата.
- Формат DOCX законопроектов — по образцу `Законопроекты/ACT. 230 — Технические исправления в Закон о Национальной Гвардии.docx`.
- Следующий свободный номер законопроекта — **271**.

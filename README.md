# IADBoost - карта репозитория

Рабочие материалы по законодательству и работе Сената штата Сан-Андреас. По уточнению пользователя 52 JSON в `Законодательная база/` составляют полную базу для новых работ; отсутствующие в срезе акты считаются отсутствующими. Архивные проекты не являются источником действующего права. Наличие проекта не подтверждает его принятие или вступление в силу.

## Основные папки

| Папка | Содержание |
|---|---|
| `Законодательная база/` | Локальный срез из 52 JSON, перечень источников и контрольные суммы. |
| `Законопроекты/` | Отдельные проекты ACT. 313-320 и ранее подготовленные инициативы SANG ACT. 299-300. Номера предварительные. |
| `Законопроекты/_ШАБЛОН/` | Неизменённый DOCX ACT. 260 - образец оформления. |
| `Компромисс/` | Сохранённые исходные материалы ACT. 286. |
| `Архив/` | Снятые и прежние проекты, исторические отчёты и сборщики. ACT. 302-312 перенесены сюда и не рассматриваются в текущем пакете. |
| `Аналитика/` | Ранее подготовленные разборы, требующие отдельной сверки с текущим срезом. |
| `Повестка/13.11.2026/`, `Повестка/19.11.2026/` | Материалы соответствующих заседаний. Для будущих PNG готовится отдельный BB-код, отдельный протокол не создаётся. |
| `Сенат/`, `Обращения/` | Материалы Сената и сохранённые обращения с исходными данными. |
| `tools/`, `tests/` | Сборка и проверки документов и материалов заседаний. |

## Текущие законопроекты

Если ACT. 315 и SANG ACT. 300 рассматривать вместе, потребуется одна согласованная редакция части 7 статьи 2 **Закона о Национальной гвардии**; SANG ACT. 299 также касается сопровождения при выходе. Номера инициатив SANG совпадают с номерами иных исторических проектов, но документы разные.

## Источники и сроки

В локальных JSON указаны метки разбора 15.11.2026 и 18.11.2026 без указанного часового пояса. Форум вернул защитную страницу, поэтому опубликованную редакцию, её актуальность и действие во времени независимо подтвердить не удалось. Прежнее указание 20.10.2026 как даты проверки ACT. 315 было ошибочным; подтверждённой даты проверки нет.

В переработанном ACT. 315 и новых ACT. 316-320 дата и поле удостоверения оставлены пустыми; оформление ранее подготовленных ACT. 313-314 сохранено. Перед подачей необходимо проверить официальную регистрацию номеров, применимые редакции, схемы территорий и процедуру принятия. Конституция предусматривает отдельную процедуру для конституционных законов; поправка 8 также требует предварительного одобрения Федеральным судом для изменений **Процессуального** и **Уголовного кодексов**, затем подписания и обнародования Губернатором.

## Сборка и проверка

DOCX оформляются по ACT. 260: шапка, краткий SECTION 1, SECTION 2 и сравнительная таблица. Названия актов выделяются полужирным; используемый шрифт - Times New Roman. В исходных цитатах удаляется невидимый форумный символ и длинное тире нормализуется до `-`. Шрифт в DOCX не встроен и должен быть установлен у читателя.

```sh
python3 tools/build_acts313_314.py
python3 tools/build_act315.py
python3 tools/build_acts316_320.py
python3 tools/build_sang_299_300.py
python3 -m unittest discover -s tests -v
```

Исторические сборщики не предназначены для выпуска текущих проектов. Для PNG Сената нужны Times New Roman Regular, Bold и Italic; при отсутствии системного шрифта `SENATE_FONT_DIR` указывает на папку с `times.ttf`, `timesbd.ttf` и `timesi.ttf`. Шрифты в репозитории не хранятся.

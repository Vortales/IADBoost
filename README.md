# IADBoost - карта репозитория

Рабочие материалы по законодательству и работе Сената штата Сан-Андреас. По уточнению пользователя 52 файла среза `Законодательная база/` составляют полную действующую базу для новых работ; отсутствующие в срезе акты считаются отсутствующими и не используются. Прежние выгрузки удалены, архивные проекты и отчёты не являются источником действующей редакции. Наличие законопроекта в репозитории не подтверждает его принятия или вступления в силу.

## Статус источников и даты

Архив законодательного среза содержал JSON с метками `parsed_at` от 15.11.2026 и 18.11.2026; часовой пояс меток не указан. Полнота среза и отсутствие иных актов приняты по уточнению пользователя. Сверка с живым форумом не удалась, поэтому время публикации и действия конкретной редакции независимо не подтверждено. В исправленных проектах 313-314 и SANG 299-300 дата в шапке не заполнена; для инициатив SANG не подтверждено и удостоверение исправлений. Даты на ранее подготовленных документах не подтверждают их подачу. Перед подачей нужно проверить применимость норм ко времени события, официальную регистрацию номеров и процедуру принятия. Принятие Сенатом не приравнивается к вступлению закона в силу. Конституционный закон «О нормативных правовых актах» в архиве отсутствует и для новых работ не используется.

## Сборка и проверка

DOCX оформляются по ACT. 260: шапка, краткий SECTION 1, SECTION 2 и сравнительная таблица. Названия актов выделяются полужирным, шрифт - Times New Roman; удаляемый текст отмечается красным, новый - зелёным. Шрифт в DOCX не встроен: для совпадающей вёрстки он должен быть установлен у читателя. Левая колонка подготовленных ранее проектов отражает источник на момент их подготовки; после замены базы её необходимо пересверять. Невидимый форумный символ удаляется и длинное тире нормализуется до `-`.

```sh
python3 tools/build_acts302_312.py
python3 tools/build_acts313_314.py
python3 tools/build_sang_299_300.py
python3 -m unittest discover -s tests -v
```

Сборка использует `tools/billkit.py` и `tools/make_acts.py`. Исторические сборщики перенесены в архив: они рассчитаны на старые редакции и не предназначены для пересборки текущих проектов. Перед запуском скриптов, создающих старые сенатские или аналитические файлы, следует проверить их входы и выходы.

Для PNG материалов Сената нужны Times New Roman Regular, Bold и Italic. Если шрифты не установлены, `SENATE_FONT_DIR` указывает на папку с `times.ttf`, `timesbd.ttf`, `timesi.ttf`. Сами шрифты в репозитории не хранятся.

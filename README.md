# IADBoost - карта репозитория

Рабочие материалы по законодательству и работе Сената штата Сан-Андреас. По уточнению пользователя 52 JSON в `Законодательная база/` составляют полную базу для новых работ; отсутствующие в срезе акты считаются отсутствующими. Архивные проекты не являются источником действующего права. Наличие проекта не подтверждает его принятие или вступление в силу.

## Основные папки

| Папка | Содержание |
|---|---|
| `Законодательная база/` | Локальный срез из 52 JSON, перечень источников и контрольные суммы. |
| `Законопроекты/` | Текущие проекты ACT. 301-303. Номера предварительные. |
| `Законопроекты/_ШАБЛОН/` | Неизменённый DOCX ACT. 260 - образец оформления. |
| `Законопроекты после правок.7z` | Сохранённый архив пользователя с ручными редакциями прежних ACT. 314 и 315. |
| `Компромисс/` | Сохранённые исходные материалы ACT. 286. |
| `Архив/` | Прежние проекты, исторические отчёты и сборщики. ACT. 299-300 и 304-307 из последнего пакета перенесены в архив; старые архивные ACT. 302-312 - другие документы. |
| `Аналитика/` | Ранее подготовленные разборы, требующие отдельной сверки с текущим срезом. |
| `Повестка/13.11.2026/`, `Повестка/19.11.2026/` | Материалы соответствующих заседаний. Для будущих PNG готовится отдельный BB-код, отдельный протокол не создаётся. |
| `Сенат/`, `Обращения/` | Материалы Сената и сохранённые обращения с исходными данными. |
| `tools/`, `tests/` | Сборка и проверки документов и материалов заседаний. |

## Текущие законопроекты

Папки выпусков находятся внутри `Законопроекты/`. Каждый проект составлен по локальному срезу и не считается принятым. По поручению пользователя в рабочем пакете оставлены только ACT. 301-303.

| Номер | Предмет | Папка |
|---|---|---|
| 301 (ранее 313) | Освобождение, сопровождение и выход с объекта | `Законопроекты 301 - освобождение и выход/` |
| 302 (ранее 314) | Вызов начальства задержанного и его статус | `Законопроекты 302 - вызов и статус начальства/` |
| 303 (ранее 315) | Режим территорий, доступ и связанные положения | `Законопроекты 303 - режим территорий/` |

Прежний ACT. 316 об обыске в суде удалён из текущего списка по поручению пользователя. Действующее положение **Конституционного закона о судебной системе** этим пакетом не изменяется. Исторические проекты с совпадающими номерами в `Архиве/` остаются другими документами.

ACT. 299-300 SANG и ACT. 304-307 перенесены в `Архив/Законопроекты 299-300 и 304-307 (перенесены в архив)/` без изменения DOCX и пояснений. Они не входят в текущий пакет. ACT. 303 не изменяет положение **Закона о Национальной гвардии** о мерах на военных объектах; его локальная исходная редакция сохраняется.

## Источники и сроки

В локальных JSON указаны метки разбора 15.11.2026 и 18.11.2026 без указанного часового пояса. Форум вернул защитную страницу, поэтому опубликованную редакцию, её актуальность и действие во времени независимо подтвердить не удалось. Прежнее указание 20.10.2026 как даты проверки территориального проекта было ошибочным; подтверждённой даты проверки нет.

Дата и поле удостоверения ACT. 303 оставлены пустыми; оформление ACT. 301-302 сохранено. Перед подачей необходимо проверить официальную регистрацию номеров, применимые редакции, схему Форта и процедуру принятия. **Конституция** предусматривает предварительное одобрение Федеральным судом для изменений **Процессуального** и **Уголовного кодексов**, затем подписание и обнародование Губернатором.

## Сборка и проверка

DOCX оформляются по ACT. 260: шапка, краткий SECTION 1, SECTION 2 и сравнительная таблица. Названия актов выделяются полужирным; используемый шрифт - Times New Roman. В предлагаемых нормах отсылки к другим актам указываются без номеров их статей; точные ссылки внутри изменяемого акта сохраняются. Исходные сравнительные фрагменты не переписываются: в них удаляется невидимый форумный символ и длинное тире нормализуется до `-`. Шрифт в DOCX не встроен и должен быть установлен у читателя.

```sh
python3 tools/build_acts301_302.py
python3 tools/build_act303.py
python3 -m unittest discover -s tests -v
```

Исторические сборщики не предназначены для выпуска текущих проектов. Для PNG Сената нужны Times New Roman Regular, Bold и Italic; при отсутствии системного шрифта `SENATE_FONT_DIR` указывает на папку с `times.ttf`, `timesbd.ttf` и `timesi.ttf`. Шрифты в репозитории не хранятся.

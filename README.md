# IADBoost - карта репозитория

Рабочие материалы по законодательству и работе Сената штата Сан-Андреас. Для новых работ используется только срез `Законодательная база/`; прежние выгрузки удалены. Архивные проекты и отчёты не являются источником действующей редакции. Наличие законопроекта в репозитории не подтверждает его принятия или вступления в силу.

## Основные папки

| Папка | Содержание |
|---|---|
| `Законодательная база/` | Единый локальный срез из 53 JSON, перечень источников и контрольные суммы. В составе есть акты, уставы, материалы правоприменения и форма. |
| `Законопроекты/` | Новые отдельные проекты ACT. 302-312 и пояснения к ним. Номера локальные и предварительные. |
| `Законопроекты/_ШАБЛОН/` | Неизменённый DOCX ACT. 260 - образец оформления. |
| `Компромисс/` | Анализ ACT. 286, сопоставление десяти вариантов для EMS и сохранённые исходные проект и обсуждение. |
| `Архив/` | Прежние законопроекты, отчёты и исторические сборщики. Старые выгрузки законодательной базы удалены; подробности в `Архив/README.md`. |
| `Аналитика/` | Ранее подготовленные разборы; их редакции и выводы требуют повторной сверки с новым срезом. |
| `Повестка/13.11.2026/` | Материалы, исходные данные, итоги и протокол заседания 13.11.2026. |
| `Повестка/19.11.2026/` | Созыв и подготовленные папки для материалов нового заседания; отдельный протокол не создаётся. |
| `Сенат/` | Материалы Сената, в том числе протокол заседания 09.11.2026 и перенесённые исходные результаты голосований. |
| `Обращения/` | Ранее подготовленные обращения. |
| `tools/`, `tests/` | Сборка и проверки новых проектов, а также инструменты для материалов заседания. |

`Новая законка/`, `286/` и архив `Темы.7z` из корня удалены после проверки и сохранения нужных материалов. Результаты заседания 09.11 перемещены в `Сенат/Протокол заседания (09.11.2026)/Исходные результаты голосований 09.11.2026.txt`; они не являются дубликатом исходных данных заседания 13.11.

## Статус источников и даты

Предоставленные JSON имеют метки `parsed_at` от 15.11.2026 - это позже текущей календарной даты 20.10.2026. Дата в шапке проектов - дата подготовки, а не подтверждение подачи. Срез не проверен на живом форуме; метка разбора и содержание архива не подтверждают актуальность норм. Перед подачей нужно уточнить хронологию, проверить редакции, официальную регистрацию номеров и необходимую процедуру принятия. Принятие Сенатом не приравнивается к вступлению закона в силу.

## Сборка и проверка

DOCX оформляются по ACT. 260: шапка, краткий SECTION 1, SECTION 2 и сравнительная таблица. Названия актов выделяются полужирным, шрифт - Times New Roman; удаляемый текст отмечается красным, новый - зелёным. Шрифт в новые DOCX не встроен: для совпадающей вёрстки он должен быть установлен у читателя. В левой колонке используется локальный источник; невидимый форумный символ удаляется и длинное тире нормализуется до `-`.

```sh
python3 tools/build_acts302_312.py
python3 -m unittest discover -s tests -v
```

Сборка использует `tools/billkit.py` и `tools/make_acts.py`. Исторические сборщики перенесены в архив: они рассчитаны на старые редакции и не предназначены для пересборки текущих проектов. Перед запуском скриптов, создающих старые сенатские или аналитические файлы, следует проверить их входы и выходы.

Для PNG материалов Сената нужны Times New Roman Regular, Bold и Italic. Если шрифты не установлены, `SENATE_FONT_DIR` указывает на папку с `times.ttf`, `timesbd.ttf`, `timesi.ttf`. Сами шрифты в репозитории не хранятся.

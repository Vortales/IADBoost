# Предложения по адвокатуре

[Предложения.txt](Исходные%20данные/Предложения.txt) - исходный текст пользователя о правах адвоката при задержании. Файл перенесён без изменения содержимого; изложенные в нём варианты являются предложениями и сами по себе не подтверждают принятия поправок или действующую редакцию закона.

Ранее подготовленные проекты по отдельным вопросам адвокатуры находятся в [архивном пакете ACT. 299-300 и 304-307](../../Архив/Законопроекты%20299-300%20и%20304-307%20%28перенесены%20в%20архив%29/).

# Архив

Здесь лежит то, что не действует: снятые и заменённые редакции, ранние выпуски законопроектов и разовые материалы. Ничего из архива не используется при подготовке новых документов. Если нужна действующая редакция акта — она в `Законодательная база/`.

| Папка | Что внутри | Почему здесь |
|---|---|---|
| `Законодательная база (устаревшие редакции)/` | Редакции актов, заменённые новыми: `Закон «О деятельности офиса Генерального прокурора»` (ред. 11.10.2026), `Конституционный закон «О нормативных правовых актах»` (ред. 11.10.2026), `Правила подачи исковых заявлений` (ред. 12.10.2026), `Устав ⸱Weazel News` (ред. 11.10.2026), `Устав SANG` (ред. 16.07.2026 — заменён Уставом внутренней службы от 14.10.2026). | Дубли одного и того же акта. Правило: действует редакция с более поздним `parsed_at`. |
| `Законопроекты 230–249 (ранняя нумерация)/` | Одиночные ACT. 230–249, сводные правки ACT. 235–249 и папки выпусков 235–249, 242–247, 248–249. | Ранняя нумерация. После сдачи ACT. 259 и далее выпуски собираются в `Законопроекты/` по папкам. |
| `Законопроекты (снятые)/` | ACT. 261 — прилегающая территория SANG. | Заменён ACT. 274: там та же задача решена не запретом, а определением режима территории. |
| `Разное/` | Корневые копии сданных документов, которые дублировали папки выпусков; `Текст жалобы (папка Подал).txt`; копия ACT. 244 в краткой редакции; заявление-инициатива в старой нумерации. | Разовые материалы вне выпусков. |
| `Сенатский комплект (не актуален)/` | Комплект по Указу № 81. | Сенат не созывался, документы заменены комплектом в `Обращения/`. |
| `Скрипты сборки законопроектов/` | Генераторы ранних выпусков, включая `by_fishing260.py` — сборщик эталонного ACT. 260. | История сборки. Текущие сборщики — в `tools/`. |

Правило пополнения: снятый документ не удаляется, а переносится сюда через `git mv`, с указанием в этом файле причины и замены.

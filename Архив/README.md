# Архив

Архив хранит прежние материалы для истории и образцов оформления. Его папки не подтверждают ни принятия законопроекта, ни действующего или утратившего силу статуса опубликованного акта. Для новой работы используется локальный срез `Законодательная база/` с обязательной проверкой официальных источников.

| Папка | Содержимое |
|---|---|
| `Законопроекты 259-301 до обновления базы/` | Прежние выпуски, пояснения и отчёты перенесены без редактирования. ACT. 301 - исторический проект; его прежнее положение о сохранении неиспользованного звонка после реализации права не является текущим предложением. |
| `Законопроекты 230–249 (ранняя нумерация)/` | Ранние одиночные и сводные проекты. |
| `Законопроекты (снятые)/` | Ранее снятые документы. |
| `Справочные материалы прежней базы/` | 15 тем, отсутствующих в новом срезе: шесть документов, семь форм и две жалобы; отдельно две старые темы с теми же названиями, но другими адресами в новом срезе. Их актуальность и преемственность не установлены. |
| `Законодательная база (устаревшие редакции)/` | Редакции, ранее перенесённые при замене; использовать только для истории. |
| `Скрипты сборки законопроектов/` | Исторические сборщики и тесты, привязанные к прежним редакциям и путям. Их нельзя запускать как сборщики текущих проектов без восстановления старых входов и проверки выходного пути. |
| `Скрипты сборки аналитики до обновления базы/` | Исторические сборщики прежних аналитических отчётов. |
| `Разное/` | Разовые материалы, включая корневые копии и ранние заявления. |
| `Сенатский комплект (не актуален)/` | Ранее заменённый сенатский комплект. |

Эталон ACT. 260 сохранён в `Законопроекты/_ШАБЛОН/`; побайтная копия того же DOCX из старой папки выпуска удалена, её пояснение оставлено в архиве. Источник и лог ACT. 286 находятся в `Компромисс/Исходные данные/`.

# Архив

Архив хранит прежние материалы для истории и образцов оформления, а не как источник действующей редакции законодательства. Его папки не подтверждают принятия законопроекта или юридического статуса акта. Старые выгрузки законодательной базы удалены; по уточнению пользователя для новой работы полный состав действующих актов определяется только срезом `Законодательная база/`, а отсутствующие в нём документы не применяются. Возможности независимой проверки официальных источников и действия редакций во времени оговорены в README базы.

| Папка | Содержимое |
|---|---|
| `Законопроекты 302-312 (сняты с рассмотрения)/` | Одиннадцать папок сняты с рассмотрения и перенесены без изменения их файлов. Историческая сводка ACT. 286 сохранена отдельно; её выводы, ссылки и утверждение о дате проверки устарели и не используются. |
| `Законопроекты 259-301 до обновления базы/` | Прежние выпуски, пояснения и отчёты перенесены без редактирования. ACT. 301 - исторический проект; его прежнее положение о сохранении неиспользованного звонка после реализации права не является текущим предложением. |
| `Законопроекты 230–249 (ранняя нумерация)/` | Ранние одиночные и сводные проекты. |
| `Законопроекты (снятые)/` | Ранее снятые документы. |
| `Скрипты сборки законопроектов/` | Исторические сборщики и тесты, привязанные к прежним редакциям и путям. Для новых работ и пересборки текущих проектов не используются. |
| `Скрипты сборки аналитики до обновления базы/` | Исторические сборщики прежних аналитических отчётов. |
| `Разное/` | Разовые материалы, включая корневые копии и ранние заявления. |
| `Сенатский комплект (не актуален)/` | Ранее заменённый сенатский комплект. |

Эталон ACT. 260 сохранён в `Законопроекты/_ШАБЛОН/`; побайтная копия того же DOCX из старой папки выпуска удалена, её пояснение оставлено в архиве. Источник и лог ACT. 286 находятся в `Компромисс/Исходные данные/`.

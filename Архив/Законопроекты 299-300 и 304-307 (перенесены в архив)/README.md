# Архив законопроектов ACT. 299-300 и 304-307

По поручению пользователя эти шесть проектов перенесены из рабочей папки `Законопроекты/` в архив. Каждый DOCX и его пояснение сохранены без изменения содержимого; контрольные суммы приведены в `SHA256SUMS.txt`.

| Номер | Проект |
|---|---|
| 299 SANG | Выход с территории Форта |
| 300 SANG | Охрана военных объектов |
| 304 | Вызов прокурора по ходатайству адвоката |
| 305 | Материалы защиты |
| 306 | Устные ходатайства |
| 307 | Фактические обстоятельства |

Пояснения внутри папок являются сохранёнными историческими версиями: описания состава рабочего пакета и команд сборки в них могут быть устаревшими. Материалы архива не являются действующими законами и не входят в текущий пакет ACT. 301-303. Номера одноимённых старых проектов в других папках архива относятся к другим документам.

# Исходные архивы

[Законопроекты после правок.7z](Законопроекты%20после%20правок.7z) - сохранённый без изменений архив пользователя с прежними проектами и ручными правками. SHA-256: `6dbb2c159ae8a624840befc65360afd51e7c5b7a6c8abcf9fedcf5901e580f58`.

Архив отражает исторический состав, в том числе прежние номера ACT. 313-320 и проекты SANG. Он содержит также снятый проект ACT. 316; его наличие внутри исходного архива не возвращает проект в текущий пакет. Для новых работ используйте папку `Законопроекты/` и отдельно проверяйте действующие редакции и статус инициатив.

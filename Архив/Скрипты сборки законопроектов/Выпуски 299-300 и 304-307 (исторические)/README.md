# Исторические сборщики и проверки ACT. 299-300 и 304-307

Сохранены прежние сборщики и профильные тесты проектов, перенесённых в архив. Они привязаны к старому расположению файлов и не предназначены для запуска или выпуска текущих законопроектов. Сборку ACT. 301-303 выполняют отдельные инструменты в `tools/`.

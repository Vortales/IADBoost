# Скрипты сборки законопроектов (архив)

Одноразовые скрипты, которыми собирались конкретные законопроекты: ACT. 235–238, 239–249 и 259–269. Каждый скрипт привязан к тексту конкретного акта на момент сборки, поэтому после обновления законодательной базы он уже не воспроизведёт результат один в один.

Оставлены в архиве как история и как образцы: по ним видно, как оформлялись пары «действующая редакция — предлагаемая редакция».

Рабочие скрипты, которые остались в `tools/`:

- `make_acts.py` — генератор DOCX по образцу ACT. 230;
- `fulltext.py` — доступ к текстам актов из `Законодательная база/`;
- `pack.py` — упаковка выпуска;
- `by_act.py`, `by_act_build.py`, `fulltext_build.py` — сборка «один документ на акт»;
- `_md2docx.py` — markdown → DOCX для судебных документов и разборов;
- `check_docx.py` — проверка вёрстки готового DOCX.

# Законодательная база - локальный срез

Здесь находятся 53 JSON из предоставленного архива `Темы.7z`. Все файлы после переноса сверены с распакованным архивом по SHA-256; `SHA256SUMS.txt` позволяет повторить проверку. JSON не редактировались. Сам архив и его распакованная копия из репозитория удалены.

Источник каждого файла указан в его полях `title`, `url` и `norm_url`. В выборке есть не только законы и кодексы, но и уставы, регламенты, судебные материалы и форма. Статус конкретного документа нужно определять по его содержанию и источнику, а не по расположению в папке.

Диапазон сохранённых меток `parsed_at` - 15.11.2026, 18:35:49-18:52:44. **Эта дата позже текущей календарной даты 20.10.2026.** Метка не подтверждает фактическое время проверки, действующую редакцию форума или вступление актов в силу. Перед подачей проектов необходимо уточнить хронологию и повторно сверить официальные тексты.

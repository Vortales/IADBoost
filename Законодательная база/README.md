# Законодательная база - локальный срез

По уточнению пользователя **52 JSON из предоставленного архива составляют полную действующую базу для работы**. Акты и документы, отсутствующие в архиве, считаются отсутствующими и не используются как действующие. Единственный локальный срез для новых работ - эта папка. SHA-256 архива `Темы.7z`: `9913d270b5ea4573c7f02e7b2fcec3c7dd5f0a799488474312a434cc2844fabb`. Каждый файл после извлечения побайтно сверён с архивом; JSON не редактировались. Архив удалён из рабочей папки после сверки; исходная загрузка сохранена в истории Git.

Названия, адреса тем и сервер указаны в полях `title`, `url`, `norm_url` и `layer`. В составе есть законы и кодексы, уставы, регламенты, судебные материалы и формы; положение файла в папке не определяет юридическую силу документа.

Метки `parsed_at` относятся к 15.11.2026 (44 файла) и 18.11.2026 (8 файлов), диапазон - `2026-11-15 18:35:49` - `2026-11-18 16:20:53`; часовой пояс не указан. Метка разбора не подтверждает вступление акта в силу, неизменность текста после разбора или применимость редакции на момент конкретного события. Перед подачей необходимо проверить официальные редакции, их действие во времени и соответствие серверу.

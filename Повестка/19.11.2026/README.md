# Заседание Сената - 19 ноября 2026 года

Заседание назначено на 19:00 в зале заседаний Сената, Капитолий штата Сан-Андреас, город Лос-Сантос. Сообщение о созыве датировано 19.11.2026.

**Внимание:** после обновления законодательной базы новый срез содержит другой текст и адрес Конституционного закона «О Сенате штата Сан-Андреас». Отсылки к статье 3 и части 1 статьи 9 в готовых PNG и BB-коде созыва относятся к прежнему срезу и не подтверждаются новым. В новом тексте вопросы полномочий Спикера и кворума находятся, в частности, в статьях 7, 9 и 25. Перед публикацией требуется отдельная правовая сверка и согласование исправления; ранее выданные файлы пока не изменены.

| Папка | Содержимое |
|---|---|
| `01 Созыв` | [Созыв - PNG](01%20Созыв/Созыв%20заседания%20Сената%20-%2019.11.2026.png), [BB-код](01%20Созыв/Созыв%20заседания%20Сената%20-%2019.11.2026%20-%20BB-код.txt) и [текст](01%20Созыв/Созыв%20заседания%20Сената%20-%2019.11.2026.md). |
| `02 Повестка` | Будет подготовлена после получения вопросов заседания: PNG и BB-код. |
| `03 Итоги` | Будут подготовлены после получения результатов голосования: PNG и BB-код по образцу 13.11. |
| `04 Журнал` | Журнал заседания будет подготовлен по мере получения данных. |
| `05 Исходные данные` | Материалы, которые будут предоставлены для нового заседания. |

К каждому PNG-документу заседания готовится отдельный файл с BB-кодом для форума. Для этого и последующих заседаний отдельный протокол не создаётся: результаты фиксируются в итогах. Сведения заседания 13.11.2026 не переносятся в новые материалы как факты о заседании 19.11.2026.

PNG, BB-код и текст созыва формируются из общих данных без изменения материалов предыдущего заседания. Для сборки PNG нужны Pillow и Times New Roman Regular, Bold и Italic: в папке шрифтов должны быть `times.ttf`, `timesbd.ttf`, `timesi.ttf`. Команда перезапишет три файла созыва в своей выходной папке:

```sh
SENATE_FONT_DIR=/путь/к/шрифтам python3 tools/make_senat_session_19_11.py
```

Чтобы обновить только BB-код без пересборки PNG (Pillow и шрифты не нужны):

```sh
python3 tools/make_senat_session_19_11.py --bb-only
```

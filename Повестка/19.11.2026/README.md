# Заседание Сената - 19 ноября 2026 года

Заседание назначено на 19:00 в зале заседаний Сената, Капитолий штата Сан-Андреас, город Лос-Сантос. Сообщение о созыве датировано 19.11.2026.

| Папка | Содержимое |
|---|---|
| `01 Созыв` | [Созыв - PNG](01%20Созыв/Созыв%20заседания%20Сената%20-%2019.11.2026.png) и [текст](01%20Созыв/Созыв%20заседания%20Сената%20-%2019.11.2026.md). |
| `02 Повестка` | Будет подготовлена после получения вопросов заседания. |
| `03 Итоги` | Будут подготовлены после получения результатов голосования: PNG и BB-код по образцу 13.11. |
| `04 Журнал` | Журнал заседания будет подготовлен по мере получения данных. |
| `05 Исходные данные` | Материалы, которые будут предоставлены для нового заседания. |

Для этого и последующих заседаний отдельный протокол не создаётся: результаты фиксируются в итогах. Сведения заседания 13.11.2026 не переносятся в новые материалы как факты о заседании 19.11.2026.

PNG и текст созыва формируются из общих данных без изменения материалов предыдущего заседания:

```sh
SENATE_FONT_DIR=/путь/к/шрифтам python3 tools/make_senat_session_19_11.py
```
